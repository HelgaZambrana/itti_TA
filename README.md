# E-commerce Analytics Challenge

## Contexto
Análisis end-to-end de cuatro datasets de e-commerce para generar 
insights accionables sobre comportamiento de usuarios, ventas, 
sentiment de clientes y predicción de recompra.

## Datasets
| Dataset | Fuente | Uso en este proyecto |
|---|---|---|
| E-commerce Transactions | Kaggle | Cohortes y análisis de ventas |
| Retailrocket Events | Kaggle | Análisis de funnel y comportamiento |
| Amazon Music Reviews | Kaggle | NLP y análisis de sentiment |
| Instacart Market Basket | Kaggle | Feature engineering y modelo predictivo |

> Los datasets no están incluidos en el repo por su tamaño y licencia.
> Ver instrucciones de descarga más abajo.
